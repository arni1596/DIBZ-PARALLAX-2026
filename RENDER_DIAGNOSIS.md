# PARALLAX V3 renderer diagnosis

The 267×267 native IMAGE buffers contain finite structure and high dynamic range. Original NHITS and propagated FLAGS create real excluded samples: zero coverage, nonfinite IMAGE, OVERFLOW, OUTLIER and unknown flag bits. SOURCE alone remains eligible. Diagonal gaps and black-looking speckles coincident with those masks are source coverage/quality exclusions, not recoverable image detail. Missing samples remain transparent. This work does not reprocess exposures, repair observations or invent pixels.

The archived PNG display used one shared linear 1st–99th-percentile range (0.0129025781–0.7647500932 MJy/sr). Bright native values above that display bound were clipped in the PNG while remaining intact in the float32 buffers. Nearest-neighbor browser enlargement also made the native coarse grid conspicuous. Pan, zoom and CSS resampling can change the appearance of edges and grain; they cannot establish whether remaining fine structure is astronomical signal. No variance extension or independent artifact classifier is available.

Spectral Reveal now pools only common eligible A/B native samples, in the chosen full field or radius-45 central context, to derive identical display limits. The asinh preset takes low=q0.005, high=maximum and softness=max((q0.99−low)×0.12, (high−low)×0.0001, 1e−9). It maps nonnegative (IMAGE−low) with the normalized asinh transform. A degenerate range receives a small numerical floor. The robust linear alternative uses q0.005/q0.995 and deliberately clips tails for display. Both are grayscale intensity encodings; neither changes numerical values or certifies cross-channel calibration.

Optional bilinear presentation smoothing uses four eligible native contributors. At a mask boundary it falls back to native sampling; excluded native pixels remain transparent. It affects display luma only. Original native sampling retains the 267×267 pixel grid with nearest sampling. FITS lower-origin rows are flipped only for presentation. The archived PNGs remain available with their original audit mapping. No finer telescope resolution is created.

Shared pan, zoom, framing and coordinates keep A/B on the same mosaic grid. Bounded navigation prevents losing the image. Shared-grid geometry is not independent astrometric certification. With common coverage enabled, both layers omit the union of invalid pixels; disabling it reveals their original differing coverage and must not be interpreted as a spectral feature.

Reproducible pair evidence is in `REVEAL_SELECTION.md`, generated by `scripts/select_reveals.py`. Selected channels are 35/86, 45/75 and 25/63. All 408 numerical source hashes are checked. All 5,151 pairs are evaluated using identical valid samples, coverage, 4×4 block structure, core/annulus means and nine common linear/asinh trials. Demonstrations show supported exploratory differences in central concentration; their masks, remaining holes and calibration limitations are disclosed. Discovery records preserve settings and provenance while displayed values are recomputed from original numerical buffers. All 55 unsupported temporal comparisons remain disabled.

No original dataset, exposure or image asset was modified. Performance conclusions require the separately executed browser/runtime report; visual smoothing alone is not evidence of faster rendering or improved scientific resolution.
