# Working on PARALLAX

- Research and reviews: edit your own `team/` file on a branch or comment on your assigned GitHub Issue.
- Application source changes are blocked until the verified RC2 release ZIP is imported and checked.
- Never force-push the release branch. Submit pull requests for approval.
- Do not modify source FITS, masks, provenance JSON or unblock 55 temporal comparisons.
- No new dependencies, speculative science, redesigns, fake demo assets or silent release changes.
- Include source links and screenshots for findings; code modifications require actual test results.
- Source credit, third-party rights and AI contribution disclosure must be accurate.
- This repo records a new collaboration snapshot, not a claim that all code was written during the event.
