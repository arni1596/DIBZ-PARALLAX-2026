# DIBZ / PARALLAX — Codex operating contract

This repository is a **team collaboration scaffold**, NOT the verified PARALLAX RC2 source. Do not imply it has passed the RC2 scientific or browser tests.

## Specialist lanes
- Ishani — science accuracy, source lineage, protected evidence gates, release integration and submission.
- Bea — existing technical/data pipeline explanation, citations and reproducible issues.
- Zak — UX/UI, first-time visitor clarity, mobile and accessibility.
- Damian — storytelling, 30-second demo and pitch, grounded in actual RC2 footage.

The Outlook assignments divide preparation, not permanent exclusive duties.

## Integration safety
Parallel **read-only** reviews are fine. Only one authorized integration writer edits production code, on a branch and via review. Do not merge source files until the verified RC2 source archive has been imported and its hashes/tests checked.

## Hard rules
- Preserve the 55 blocked temporal M101 comparisons.
- No independent variability result from flagged R Draconis photometry.
- Do not invent wavelength values, epochs, WCS registration, source DOIs or scientific conclusions.
- No new scientific pipelines or dependencies during release freeze.
- Preserve provenance, source FITS and quality masks; never manipulate commit timestamps or eligibility history.
- No unverified deployment, human sign-off, or test claims.

Every review reports: observed issue, evidence/source, P0/P1 severity, smallest corrective action and owner.
