2. **Show the existing workflow in one short live sequence.** M101 spectral difference (explicitly wavelength, not time) → one real native quality decision → Passport → documented limitation.
3. **Close the actual distribution gap.** Human-approve latest branch, re-run release tests, deploy to the authorized public destination, validate without login, submit within official rules.
