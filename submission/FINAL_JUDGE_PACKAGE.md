# PARALLAX — judge package (draft, requires team approval)

## High-level description

PARALLAX is an interactive SPHEREx evidence observatory. It invites visitors to explore infrared views of the M101 galaxy, inspect selected dated observations, examine native pixel-quality evidence, and trace what they see back to source records. It demonstrates how observational context and quality checks shape responsible scientific interpretation.

## The problem

Astronomical images are compelling, but visually different pictures do not necessarily prove an astronomical object changed. Wavelength, timing, geometry, calibration and flagged measurements all matter. Public tools should make those distinctions understandable.

## What we built

A six-chapter browser journey with a real infrared mosaic, shared-display spectral comparison, curated dated observations, quality-flag inspection, documented sources and an exportable Evidence Passport. A user can see spectral structure, inspect an observation's support, and learn where the scientific conclusion must stop.

## What we can support

- M101 spectral **appearance**, not M101 brightness change over time.
- Inspection of authentic dated QR2 products, **not** registered motion or newly measured variability.
- Pixel-level flags and eligibility, **not** discovery of 3I/ATLAS or new stellar variability.
- Traceable metadata and source URLs, **not** agency endorsement or full calibration certification.

## Scientific inputs

NASA/IPAC IRSA SPHEREx products. QR2 collection DOI: https://doi.org/10.26131/IRSA652 . The M101 public demonstration FITS is reported byte-matched to the retained parent, but release DOI and calibration lineage remain unresolved. Do not assign QR3/DR1 collection identifiers to this mosaic.

## Challenge alignment and limitation

This project responds to the 2026 Planet X and SPHEREx challenge through public inspection of SPHEREx observations. The current build does not offer arbitrary-coordinate temporal movies, independently measured moving-object detection, or the complete challenge target set. These capabilities must not be implied.
