# PARALLAX — FIND → SEE → VERIFY

RC2, November 14, 2026. Local technical content; not published, submitted or certified eligible.

## High-level summary

PARALLAX makes infrared astronomy inspectable. Visitors explore an authentic M101 mosaic at different wavelengths, examine independently dated SPHEREx observations, inspect native pixels and quality flags, and export an Evidence Passport. It separates what a picture shows from what the observations can support. The current release is a bounded educational investigation using packaged observations—not an arbitrary-coordinate archive service, registered motion detector or discovery engine.

## Detailed description

FIND opens the existing M101 field. SEE compares two of 102 nominal infrared channels using a shared native grid, explicit common-coverage masks and shared display settings. Channels are wavelengths, not dates. Selected-region statistics are descriptive; they do not establish calibrated photometry or physical cause.

Time and Evidence expose four Atlas-field observations across three calendar dates. Native grids, approximate wavelengths and display stretches remain independent. The marker is a predicted position, not measured detection. Quality overlays reveal actual exclusions. Existing R Draconis field inspection and the eleven-image M101 dated gallery remain available. All 55 unsupported temporal comparisons remain disabled.

VERIFY exposes source identifiers, timestamps, hashes, processing and limits. The Passport exports the selected Atlas product and real inspected/display state, not a discovery certificate. Published NASA activity findings are attributed externally, not reproduced measurements. The application uses existing React/TypeScript/Vite and existing scientific Python preparation; runtime evidence logic is deterministic, not an LLM guess.
